# Windows に入れる手順

この手順は、Windows で Claude Code を入れ、この種を置き、相棒を起こすところまでです。
1 段ずつ進めてください。各段に「見る所」があります。違ったら、その段で止まってください。

## 先に言っておくこと（ここだけは読んでから始めてください）

### 要るもの

- **Claude の有料の契約（Pro / Max / Team / Enterprise のどれか）。** 無料の Claude では Claude Code は使えません（公式の setup の頁）。契約と料金はご本人と Anthropic 社の間のもので、この種の側では無料にできません。
- **Windows 10（1809 以降）か Windows 11。** メモリ 4 GB 以上。インターネットにつながっていること（公式の setup の頁）。
- **PowerShell。** Windows に最初から入っています。
- 会社のパソコンの場合は、**入れてよいかを先に管理の方に確かめてください。** 会社の決まりで、入れる操作が止められていることがあります。

### 窓の印

この手順では、打つ場所を行ごとに印で示します。

| 印 | 打つ場所 | 見分け方 |
|---|---|---|
| 🟦 | PowerShell の窓 | 行の頭が `PS C:\` で始まる |
| 🟩 | 相棒（Claude Code）の入力欄 | 起動した後の、枠で囲まれた入力欄 |
| 🌐 | ブラウザ | — |

窓は 2 つ並べて開いておくと、取り違えにくくなります。

### つまずく所（先に言います）

うちが Windows で実際に入れて、つまずいた所です。うちの記録は Windows Server 2022 の管理者の口座で取ったものです。Windows 10 / 11 の普通の口座で通した記録はまだありません。

1. **入れ終わっても `claude` が「認識されない」と出ることがある。** 入れる道具は「完了」と言うのに、起動の道（PATH）を足さないことがありました。直し方は 3 段目にあります。直す 3 行は Windows の環境変数を変えるので、打つかはご自分で決めてください。
2. **ログインすると、Claude のサイトでつないだ連携（Gmail・Google カレンダーなど）が付いてくる。** この種のフォルダの設定で全部止めてあります。ただし、**このフォルダの外で起動すると止まりません。** 相棒は、いつもこのフォルダで起動してください。
3. **起動するたびに «おまかせ（auto mode）» に戻る。** Shift + Tab で «毎回確認（manual mode）» にしても、次の起動で戻ります。ずっと毎回確認にしたいときは、はじめの聞き取りで「毎回確認」を選んでください。
4. **起動のたびに、版が自動で上がることがある。** 入れる 1 行は、更新がゆっくりな «stable» の形にしてあります。
5. **新しい描き方を試すかを聞かれたら «Not now»。** うちで試した版（2.1.285）では、ここで Yes を選ぶと入力欄が画面の下に隠れました。版によっては出ない画面です。
6. **PowerShell の窓と、相棒の窓を取り違える。** 相棒の入力欄に 🟦 の行を打つと、相棒がそれを実行します。打つ前に、行の頭が `PS C:\` かを見てください。
7. **貼った行が崩れる。** 先頭の 1 文字が落ちる、長い行の途中に改行が入る、長い日本語の頼みごとが途中で切れる、の 3 通りが起きました。この手順の行はすべて 90 文字以下にしてあります。赤い字が出たら、まず行の先頭を見てください。
8. **頭に `!` を付けた行は、相棒の決まりも止める設定も通らない。** 相棒は、止められた操作を「`!` を付けて打ってください」と案内することがあります。`!` の行はご自分が打つ命令で、結果はご自分の責任です。何をする行かを確かめてから打ってください。
9. **鍵やパスワードを、相棒の入力欄に貼らない。** 相棒は受け取らない決まりですが、貼った文字は会話の記録に残ります。

ほかに、次の 2 つも先に言っておきます。

- **落とした ZIP を展開すると、同じ名前のフォルダが 2 重になることがある。** 置く場所は «`CLAUDE.md` が直接見えるフォルダ» です（5 段目）。
- **初めてのフォルダで起動すると、«このフォルダを信頼するか» の画面が出る。** この種の設定が並んで表示されます。読んでから、信頼する側を選んでください（7 段目）。

---

## 1. Claude の契約を確かめる 🌐

1. ブラウザで claude.ai を開き、ログインします。
2. 契約が Pro / Max / Team / Enterprise のどれかであることを確かめます。

- 見る所: 有料の契約になっている。
- 無料のままなら、ここで止まってください。この種は有料の契約が無いと動きません。

## 2. PowerShell を開く

1. 画面左下のスタートを押し、「PowerShell」と打ちます。
2. 「Windows PowerShell」を開きます（管理者として開く必要はありません）。

- 見る所: 行の頭が `PS C:\Users\<あなたの名前>>` になっている。

## 3. Claude Code を入れる 🟦

次の 1 行を打ちます（公式の setup の頁の «stable» の行）。

```powershell
& ([scriptblock]::Create((irm https://claude.ai/install.ps1))) stable
```

- 見る所: しばらく何も出ずに待ちます（公式: 進み具合は表示されません）。最後に「完了」の旨が出ます。

終わったら、**PowerShell の窓を閉じて、新しく開き直し**、次を打ちます。

```powershell
claude --version
```

- 見る所: 版の番号（例: `2.1.295 (Claude Code)`）が出る。
- **「認識されません（not recognized）」と出たら**、次の 3 行を 1 行ずつ打ちます（公式の troubleshoot-install の頁の Windows の 2 行を、貼ったときに崩れないよう 3 行に割った物。中身は同じです）。これは Windows の «起動の道» を足す操作です。打つかはご自分で決めてください。

```powershell
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
$newPath = "$currentPath;$env:USERPROFILE\.local\bin"
[Environment]::SetEnvironmentVariable('PATH', $newPath, 'User')
```

  打ったら、窓を閉じて開き直し、もう一度 `claude --version` を打ちます。

## 4. 種を落とす 🌐

1. ブラウザで `https://github.com/tedit2020/numbers-seed` を開きます。
2. 緑の «Code» のボタン → «Download ZIP» を押します。
3. 「ダウンロード」フォルダに ZIP が保存されます。

## 5. 種を置く

1. エクスプローラーで「ダウンロード」を開き、落とした ZIP を右クリック → «すべて展開» → «展開» を押します。
2. 展開したフォルダを開いていき、**`CLAUDE.md` と `README.md` が直接並んでいるフォルダ**を見つけます（同じ名前のフォルダが 2 重になっていることがあります）。
3. そのフォルダの名前を `aibo` に変えます。
4. その `aibo` フォルダを、`C:\Users\<あなたの名前>` の中へ移します（「ドキュメント」の中ではなく、その 1 つ上です）。

確かめます。🟦

```powershell
Test-Path "$HOME\aibo\CLAUDE.md"
Test-Path "$HOME\aibo\.claude\settings.json"
```

- 見る所: 2 行とも `True`。
- `False` なら、置いた場所か、フォルダの階層が 1 つずれています。この段の 2 に戻ってください。

## 6. 相棒を起こす 🟦

```powershell
cd "$HOME\aibo"
claude
```

- 🔴 相棒は、**いつもこのフォルダで**起こしてください。ほかのフォルダで起こすと、連携を止める設定が効きません。

## 7. はじめて起こしたときに出る画面

版によって、出る画面と順番が変わります。出たものだけ、次のとおり選んでください。

| 出る画面 | 選ぶもの |
|---|---|
| 画面の色（テーマ）を選ぶ | 見やすいもの |
| ログインの方法 | Claude の契約のアカウントでログインする方。ブラウザが開くので、そこでログインします |
| このフォルダを信頼するか | 表示される設定を読んでから、信頼する側（Yes）。この種の設定は «このフォルダの中だけ書いてよい» «消す・送る系の命令は禁止» です |
| 新しい描き方を試すか | Not now |
| おまかせ（auto mode）が既定になった、のお知らせ | 読んで進む |

- 見る所: 画面の下に入力欄が出て、その下に `auto mode on` のような表示がある。

## 8. 相棒に話しかける 🟩

入力欄に、何か 1 言打ちます。

```text
こんにちは
```

- 見る所: 相棒が「はじめに 5 分ほど、私の働き方を決める質問をさせてください」のように言い、質問を 1 つずつ始める。
- 始まらなければ、🟩 に `はじめの設定をしたい` と打ちます。

ここから先は、相棒が 1 問ずつ案内します。わからなくなったら、「わからない」「もっと詳しい手順を教えてほしい」と打ってください。

## 9. 次の日から

🟦 PowerShell を開いて、次の 2 行です。

```powershell
cd "$HOME\aibo"
claude
```

- 終わるときは 🟩 に `/exit` と打ちます。
