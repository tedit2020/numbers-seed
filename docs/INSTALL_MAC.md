# Mac に入れる手順

この手順は、Mac で Claude Code を入れ、この種を置き、相棒を起こすところまでです。
1 段ずつ進めてください。各段に「見る所」があります。違ったら、その段で止まってください。

🟡 Mac の手順は、公式の案内をもとに書いています。まっさらな Mac で最初から通した記録は、まだありません。

## 先に言っておくこと（ここだけは読んでから始めてください）

### 要るもの

- **Claude の有料の契約（Pro / Max / Team / Enterprise のどれか）。** 無料の Claude では Claude Code は使えません（公式の setup の頁）。契約と料金はご本人と Anthropic 社の間のもので、この種の側では無料にできません。
- **macOS 13.0 以降。** メモリ 4 GB 以上。インターネットにつながっていること（公式の setup の頁）。
- **ターミナル。** Mac に最初から入っています（アプリケーション → ユーティリティ → ターミナル）。

### 窓の印

| 印 | 打つ場所 | 見分け方 |
|---|---|---|
| 🟦 | ターミナル（相棒を起こす前） | 行の終わりが `%` で、そのあとに打てる |
| 🟩 | 相棒（Claude Code）の入力欄 | 起動した後の、枠で囲まれた入力欄 |
| 🌐 | ブラウザ | — |

Mac では、同じターミナルの窓の中で、相棒を起こす前（🟦）と起こした後（🟩）が入れ替わります。設定を置き換えるときなど、🟦 の行を打つ段では、**ターミナルの窓をもう 1 つ開いて**（cmd + N）そちらに打ってください。

### つまずく所（先に言います）

1. **入れ終わっても `claude` が見つからない（command not found）ことがある。** 起動の道（PATH）に、入れた場所が入っていないときです。直し方は 2 段目にあります（公式の troubleshoot-install の頁）。
2. **ログインすると、Claude のサイトでつないだ連携（Gmail・Google カレンダーなど）が付いてくる。** この種のフォルダの設定で全部止めてあります。ただし、**このフォルダの外で起動すると止まりません。** 相棒は、いつもこのフォルダで起動してください。
3. **起動するたびに «おまかせ（auto mode）» に戻る。** Shift + Tab で «毎回確認（manual mode）» にしても、次の起動で戻ります。ずっと毎回確認にしたいときは、はじめの聞き取りで「毎回確認」を選んでください。
4. **起動のたびに、版が自動で上がることがある。** 入れる 1 行は、更新がゆっくりな «stable» の形にしてあります。
5. **Finder では `.claude` フォルダが見えない。** 名前が `.` で始まるフォルダは、Mac では隠れています。見えなくても、そこに在ります。見たいときは Finder で cmd + Shift + . （ピリオド）を押します。
6. **相棒を起こした窓に、🟦 の行を打ってしまう。** 相棒の入力欄に 🟦 の行を打つと、相棒がそれを実行します。打つ前に、どちらの窓かを見てください。
7. **貼った行が崩れる。** 先頭の 1 文字が落ちる、長い日本語の頼みごとが途中で切れる、が Windows で起きました。この手順の行はすべて 90 文字以下にしてあります。
8. **頭に `!` を付けた行は、相棒の決まりも止める設定も通らない。** 相棒は、止められた操作を「`!` を付けて打ってください」と案内することがあります。`!` の行はご自分が打つ命令で、結果はご自分の責任です。
9. **鍵やパスワードを、相棒の入力欄に貼らない。** 相棒は受け取らない決まりですが、貼った文字は会話の記録に残ります。

ほかに、次の 2 つも先に言っておきます。

- **ホームのフォルダ（家の形のアイコンのフォルダ）そのもので起動しない。** 公式の案内では、ホームで起動すると «このフォルダを信頼するか» の画面が毎回出ます。この種は、ホームの中の `aibo` フォルダで起動します。
- **初めてのフォルダで起動すると、«このフォルダを信頼するか» の画面が出る。** この種の設定が並んで表示されます。読んでから、信頼する側を選んでください（6 段目）。

---

## 1. Claude の契約を確かめる 🌐

1. ブラウザで claude.ai を開き、ログインします。
2. 契約が Pro / Max / Team / Enterprise のどれかであることを確かめます。

- 無料のままなら、ここで止まってください。

## 2. Claude Code を入れる 🟦

ターミナルを開き、次の 1 行を打ちます（公式の setup の頁の «stable» の行）。

```bash
curl -fsSL https://claude.ai/install.sh | bash -s stable
```

- 見る所: しばらく何も出ずに待ちます（公式: 進み具合は表示されません）。

終わったら、**ターミナルの窓を閉じて、新しく開き直し**、次を打ちます。

```bash
claude --version
```

- 見る所: 版の番号（例: `2.1.295 (Claude Code)`）が出る。
- **`command not found` と出たら**、次の 2 行を 1 行ずつ打ちます（公式の troubleshoot-install の頁、zsh の行）。起動の道を足す操作です。打つかはご自分で決めてください。

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

  打ったら、もう一度 `claude --version` を打ちます。

## 3. 種を落とす 🌐

1. ブラウザで `<種の置き場の URL>` を開きます。
2. 緑の «Code» のボタン → «Download ZIP» を押します。
3. 「ダウンロード」フォルダに保存されます。Safari では、自動で展開されてフォルダになっていることがあります。

## 4. 種を置く

1. Finder で「ダウンロード」を開きます。ZIP のままなら、ダブルクリックで展開します。
2. 展開したフォルダを開き、**`CLAUDE.md` と `README.md` が直接並んでいるフォルダ**を見つけます。
3. そのフォルダの名前を `aibo` に変えます。
4. その `aibo` フォルダを、ホームのフォルダ（家の形のアイコン、あなたの名前のフォルダ）の中へ移します。

確かめます。🟦

```bash
ls ~/aibo/CLAUDE.md ~/aibo/.claude/settings.json
```

- 見る所: 2 つのファイルの名前がそのまま出る。
- `No such file or directory` と出たら、置いた場所か、フォルダの階層が 1 つずれています。この段の 2 に戻ってください。

## 5. 相棒を起こす 🟦

```bash
cd ~/aibo
claude
```

- 🔴 相棒は、**いつもこのフォルダで**起こしてください。ほかのフォルダで起こすと、連携を止める設定が効きません。

## 6. はじめて起こしたときに出る画面

版によって、出る画面と順番が変わります。出たものだけ、次のとおり選んでください。

| 出る画面 | 選ぶもの |
|---|---|
| 画面の色（テーマ）を選ぶ | 見やすいもの |
| ログインの方法 | Claude の契約のアカウントでログインする方。ブラウザが開くので、そこでログインします |
| このフォルダを信頼するか | 表示される設定を読んでから、信頼する側（Yes）。この種の設定は «このフォルダの中だけ書いてよい» «消す・送る系の命令は禁止» です |
| おまかせ（auto mode）が既定になった、のお知らせ | 読んで進む |

## 7. 相棒に話しかける 🟩

```text
こんにちは
```

- 見る所: 相棒が「はじめに 5 分ほど、私の働き方を決める質問をさせてください」のように言い、質問を 1 つずつ始める。
- 始まらなければ、🟩 に `はじめの設定をしたい` と打ちます。

わからなくなったら、「わからない」「もっと詳しい手順を教えてほしい」と打ってください。

## 8. 次の日から

🟦 ターミナルを開いて、次の 2 行です。

```bash
cd ~/aibo
claude
```

- 終わるときは 🟩 に `/exit` と打ちます。
