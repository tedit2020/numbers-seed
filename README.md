# ナンバーズの種（無料版）

Claude Code を入れたけれど、「さて、何から始めれば？」で止まってしまった方のための、**相棒の種**です。

落として、展開して、手順どおりに置いて、起動して話しかけるだけ。
相棒が最初に 5 分ほど質問をして、あなたの呼び方・仕事・話し方を覚え、次の日からその形で手伝います。

中身は文章のファイルだけです。プログラムは入っていません。

---

## 先に言っておくこと 2 つ

1. **Claude の契約は、ご本人のものです。** Claude Code を使うには、Claude の有料の契約（Pro / Max / Team / Enterprise のどれか）が要ります。無料の Claude では使えません。この種は無料ですが、Claude の契約と料金は、ご本人と Anthropic 社の間のもので、こちらでは無料にできません。
2. **困ったときの出口があります。** この種は「自分で入れて、自分で育てる」ための物です。自分でやってみて、手に余ると感じたら、うちが入れに伺う有料の派遣があります（下の «困ったら»）。

## 要るもの

| 要るもの | 中身 |
|---|---|
| Claude の契約 | Pro / Max / Team / Enterprise のどれか（無料では使えません） |
| パソコン | Windows 10（1809 以降）/ Windows 11、または macOS 13.0 以降。メモリ 4 GB 以上 |
| インターネット | 入れるときも、使うときも要ります |
| 会社のパソコンなら | 入れてよいかを、先に管理の方に確かめてください |

（要件は Claude Code の公式の setup の頁より。2026-10-09 に確かめました）

## つまずく所（先に言います）

うちが実際に入れて、つまずいた所です。詳しくは手順の頁の冒頭に、OS ごとに書いてあります。

| つまずく所 | Windows | Mac |
|---|---|---|
| 入れ終わっても `claude` が見つからない | 起きた。直す 3 行あり | 起きうる（公式）。直す 2 行あり |
| ログインすると、メールや予定表の連携が付いてくる | この種のフォルダでは止めてある。**フォルダの外で起動すると止まらない** | 同じ |
| 起動のたびに «おまかせ» に戻る | 起きた | 同じ（公式） |
| 版が自動で上がる | 起きた。«stable» の形で入れる | 同じ |
| 新しい描き方を試すと、入力欄が隠れる | 起きた（版 2.1.285）。«Not now» を選ぶ | 測っていない |
| 窓の取り違え（相棒の入力欄に命令を打つ） | 起きた。窓の印 🟦 🟩 で見分ける | 同じ窓の中で入れ替わるので注意 |
| 貼った行が崩れる・途中で切れる | 起きた。行は 90 文字以下に | 測っていない |
| `!` を付けた行は、止める設定を通らない | 起きた。打つ前に何の行かを確かめる | 同じ |
| ZIP を展開するとフォルダが 2 重になる | «`CLAUDE.md` が直接見えるフォルダ» を置く | 同じ |
| `.claude` フォルダが見えない | — | 隠れているだけで、在る |

- 入れ方: [Windows](docs/INSTALL_WINDOWS.md) / [Mac](docs/INSTALL_MAC.md)
- Windows の記録は、Windows Server 2022 の管理者の口座で取ったものです。Mac は公式の案内をもとに書いていて、まっさらな Mac で最初から通した記録はまだありません。

## 無料でできること / できないこと

| | 無料（この種） | 有料（ナンバーズの派遣） |
|---|---|---|
| 入れる人 | ご自分 | うちが伺って入れる |
| 相棒の聞き取り（呼び方・仕事・役割・話し方・動き方） | ある | ある |
| 決めごとの帳面 | ある | ある |
| メール・予定表などとの連携 | **止めたまま**（つながない） | 1 つずつ聞いて、守りを足してからつなぐ |
| 守り | 1 段（設定の «禁止» の一覧と、相棒の決まりの文） | 3 段（決まり / 確認 / 機械の関所） |
| 相棒の下で動く手伝い役（調べ物・検品を分担する AI） | なし | 付けて、育て方を伴走する |
| 仕事ごとの専用の技能・うちが積み上げた型 | なし | 仕事に合わせて入れる |
| 困ったとき | この README と手順の頁 | 相談できる |

## 置くとどうなるか（中身の一覧）

```
aibo/
├─ README.md                  … この 1 枚
├─ CLAUDE.md                  … 相棒の構え（起動するたびに相棒が読む）
├─ .claude/
│   ├─ settings.json          … 連携を止める・消す/送る系の命令を禁止する設定
│   └─ skills/hajime-no-kikitori/SKILL.md … はじめの聞き取りの手順
├─ notebook/
│   ├─ house-rules.md         … 決めごとの帳面（聞き取りの答えがここに書かれる）
│   └─ todo.md                … やることの帳面
├─ onboarding/                … 設定の案を相棒が書く場所
├─ work/                      … 相棒が作った下書きを置く場所
└─ docs/                      … 入れ方（Windows / Mac）と設定の説明
```

- 設定の 1 行ずつの意味は [docs/SETTINGS.md](docs/SETTINGS.md) にあります。

## なぜ相棒は、自分の設定を書かないのか

相棒が自分の設定を書き換えられると、「確認なしで何でもしてよい」に自分で変えてしまえます。
相棒の思い違いや、読んだファイルに紛れ込んだ悪い指示でも、同じことが起きます。
だから、設定を変えるのは必ずあなたの手と目を通す決まりにしています（変えるのは «毎回確認» を選んだ時の 1 回だけです）。
